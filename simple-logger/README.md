# Simple Logger (Automation Task)

## Description
A simple automation that logs a greeting along with the current UTC timestamp each time it runs.
Based on the [Scheduled Logger](https://github.com/wso2/integration-samples/tree/main/integrator-default-profile/samples/scheduled-logger) sample.

## Usage Instructions

### Run locally

```bash
bal run
```

Expected output:

```
>>> [Simple Logger] Hello! Current timestamp: 2026-10-16T10:00:00.000Z
```

### Deploy on **WSO2 Cloud**

1. Deploy this integration on **WSO2 Cloud** as an **Automation**.
2. Each run logs the greeting and the current timestamp.
